# 平均律

## 题目背景

>只见盈盈的双手在键盘上游移，速度越来越快。毫无秩序的音符间填上了其他的音符。一堆杂乱无章的符中诞生了小小的图案,然后无数的图案开始交织,形成了更大的图案。  
>然后，就从离散走向了连续!

_为了题面的简洁性，我删去了其中与音乐有关的内容。_

## 题目描述

我们定义一个数的近似分数为：  
在允许的误差内分母最小的分数  
_Tips:这里允许分数的分母为 $1$_

请问允许的误差为 $\pm\delta$ 时，  
任选一数 $\xi\in\mathbb{R}$，  
其近似分数的分母为 $n$ 的概率是多少？

## 输入格式

本题有多组数据，第一行输入一个整数 $T$，表示数据组数。  

对于每一组询问，我们给出 $n,a,b$，  
为了避免浮点误差，令 $\delta=\frac ab$。  

## 输出格式

对于每组数据，一行输出一个数表示概率。  
为了避免整型溢出，输出分数对 $998244353$ 取模后的结果即可。

### 数据范围

| 子任务 | 分值 | 限制 |
| :----------: | :----------: | :----------: |
| $0$ | $10$ | $n\in[1,10^7]$ |
| $1$ | $20$ | $d(n)\in[1,10^2]$ |
| $2$ | $70$ | - |

对于 $100\%$ 数据，保证 $n\in[1,10^{15}],d(n)\in[1,2\times10^4]$。  
其中 $d(n)$ 为因数个数函数。
