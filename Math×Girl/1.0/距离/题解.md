# 操作次数

设 $x=\max\{a,b\},y=\min\{a,b\},x'=ky'$  
我们要最小化 $ans:=|x-x'|+|y-y'|$


给定 $x>y$，设 $y'\mid x'$。  
求 $\min\{|x-x'|+|y-y'|\}$ 的期望。  
提示：一个很显然的上界是 $(y-1)$。

$$v^2<y^2-x$$
$$v\sim \frac{xy}{\sqrt{x\ln y}}$$


$$\frac{xy^2}{\ln y}<y^2-x$$

## 输出格式

第一行输出最小的操作数(即 $|x|+|y|$ 的最小值).\
第二行输出操作后的两个数$a$和$b$(即$a+x$和$b+y$的值)，中间用空格隔开.\
(如果有多种情况，则输出$a$最大的那一种).

## 样例 #1

### 样例输入 #1

```
4 12
```

### 样例输出 #1

```
0
4 12
```

## 样例 #2

### 样例输入 #2

```
15 33
```

### 样例输出 #2

```
2
16 32
```

## 提示

对于$10\%$的数据，有$a,b<=10^3$；\
对于$50\%$的数据，有$a,b<=10^4$；\
对于$100\%$的数据，有$a,b<=10^{16}$


# 操作次数

## 题目描述

给你两个数$a$和$b$，每次操作可以进行如下四个操作中的一种操作:\
$1.将a加1$\
$2.将a减1$\
$3.将b加1$\
$4.将b减1$\
求最少进行多少次操作，才能使$a \% b = 0$或$b\%a=0$.
# 简要题意
给定两个数$a,b$，求 $(a+x)\%(b+y)=0$ 或 $(b+y)\%(a+x)=0$ 时 $|x|+|y|$ 的最小值($x,y$可为负数).

## 输入格式

只有一行两个数，分别表示$a$和$b$.

## 输出格式

第一行输出最小的操作数(即 $|x|+|y|$ 的最小值).\
第二行输出操作后的两个数$a$和$b$(即$a+x$和$b+y$的值)，中间用空格隔开.\
(如果有多种情况，则输出$a$最大的那一种).

## 样例 #1

### 样例输入 #1

```
4 12
```

### 样例输出 #1

```
0
4 12
```

## 样例 #2

### 样例输入 #2

```
15 33
```

### 样例输出 #2

```
2
16 32
```

## 提示

对于$10\%$的数据，有$a,b<=10^3$；\
对于$50\%$的数据，有$a,b<=10^4$；\
对于$100\%$的数据，有$a,b<=10^?$（不确定最优解可以承受多大的计算量）
