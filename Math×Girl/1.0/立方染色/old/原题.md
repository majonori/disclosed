# 米尔嘉

## 题目背景

暂无。

## 题目描述

在 $n$ 维中有 $n$ 维超立方体「n-cube」。  
有黑白两种不同的 单位 n-cube「I-n-cube」。  
由 $a^n$ 个 I-n-cube 可以堆砌出 棱长为 $a$ 的大n-cube「a-n-cube」。

请问：  
a-n-cube 中的每一个 b-n-cube 中都恰好只有一个 黑色的 I-n-cube 的颜色分布方案有几种？  
对于所有数据，保证 $a\ge b$。  

由于答案可能很大，你只需要输出方案数对 $998244353$ 取模后的结果就可以了。  

## 输入格式

三个正整数 $n,a,b$。

## 输出格式

一个数表示取模后的方案数。

## 样例 #1

### 样例输入 #1

```text
2 3 2
```

### 样例输出 #1

```text
8
```

## 样例 #2

### 样例输入 #2

```text
5 3 2
```

### 样例输出 #2

```text
444076651
```

## 样例 #3

### 样例输入 #3

```text
2 100 3
```

### 样例输出 #3

```text
792303199
```
