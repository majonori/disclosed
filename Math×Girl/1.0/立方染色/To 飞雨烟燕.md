# 立方染色

## 题目背景

暂无。

## 题目描述

在 $n$ 维中有 $n$ 维超立方体「n-cube」。  
有黑白两种不同的 单位 n-cube「I-n-cube」。  
由 $a^n$ 个 I-n-cube 可以堆砌出 棱长为 $a$ 的大 n-cube「a-n-cube」。

请问：  
a-n-cube 中的每一个 b-n-cube 中都恰好只有一个 黑色的 I-n-cube 的颜色分布方案有几种？  
对于所有数据，保证 $a\ge b$。  

由于答案可能很大，你只需要输出方案数对 $998244353$ 取模后的结果就可以了。  

## 输入格式

三个正整数 $n,a,b$。

## 输出格式

一个数表示取模后的方案数。

## 样例 #1

### 样例输入 #1

```text
2 3 2
```

### 样例输出 #1

```text
8
```

## 样例 #2

### 样例输入 #2

```text
5 3 2
```

### 样例输出 #2

```text
444076651
```

## 样例 #3

### 样例输入 #3

```text
2 100 3
```

### 样例输出 #3

```text
792303199
```

# 思路

其实这题本质上是高维空间中的“推箱子”问题。

### 转换

例如 `2 3 10` 答案是 `261`，我们以此举例：  
把每个 黑色的 I-n-cube 作为边角点，做出一个 b-n-cube：

例如这这里是两种合法的铺法：

![](https://cdn.luogu.com.cn/upload/image_hosting/9ssq5btt.png)

可以发现现在问题就转换为了密铺问题

### 二维

对于二维情况答案很简单：

我们只用考虑边缘上的 $O(2a/b)$ 个 b-n-cube 即可，因为这样可以确定唯一的密铺。  
接着可以证明密铺一定是一条一条的，就像“推箱子”一样，每次推动一条，若卡住就不能推。  
这样可以做到不漏。

现在要么就是先往右推再往上推，要么就是先往上推再往右推。  
由于推了一边就会卡住另一边，所以要使得可以推另一边，就得这边全推。

于是有：
$$ans=2\times(a\%b\times b^{\lfloor a/b+1\rfloor}+(b-a\%b)\times b^{\lfloor a/b\rfloor})-b^2$$

tips:  
这里乘 $2$ 是考虑先往右推还是往上推，为了避免两边都全推的情况，所以还要减去 $b^2$。

### 高维

对于三维来说，我们都要考虑边缘面上的 $O(3(a/b)^2)$ 个 b-n-cube 才可以确定唯一的密铺。  
那对于更加复杂的情况手推公式似乎是不可能的了，也没有足够多/大的样例能够让机器注意到公式。

如果让程序搜索推箱子的过程，时间复杂度就是答案的大小，而且状压将会非常恐怖。
