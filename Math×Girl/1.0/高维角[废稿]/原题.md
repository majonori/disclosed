# 整除欧拉函数

## 题目背景

## 题目描述

$109^\circ28'16.39''$ 

## 输入格式

一个正整数 $n$。

## 输出格式

一个角 $\theta$。  
请依次输出它的角度、角分、角秒，中间用 `'` 分隔，  
其中角秒要保留两位小数。

## 样例 #1

### 样例输入 #1

```text
2
```

### 样例输出 #1

```text
120'0'0.00'
```

## 样例 #2

### 样例输入 #2

```text
3
```

### 样例输出 #2

```text
109'28'16.39'
```

## 提示

### 数据范围

| 子任务 | 分值 | 限制 |
| :----------: | :----------: | :----------: |
| $0$ | $10$ | $n\in[1,10^7]$ |
| $1$ | $20$ | $d(n)\in[1,10^2]$ |
| $2$ | $70$ | - |

对于 $100\%$ 数据，保证 $n\in[1,10^{15}],d(n)\in[1,2\times10^4]$。  
其中 $d(n)$ 为因数个数函数。
